# Эстетика — салон красоты в Крымске

Лендинг-визитка салона «Эстетика» (г. Крымск, ул. Синёва, 36А).

Весь сайт — один файл `index.html`. Фото встроены в него, поэтому достаточно открыть файл в браузере или выложить на любой статический хостинг (например, GitHub Pages).

## Стек
- Tailwind CSS (CDN)
- GSAP + ScrollTrigger — появление блоков и параллакс
- Lenis — плавная прокрутка
- Swiper — галерея работ
- Lucide — иконки
